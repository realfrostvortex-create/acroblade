# Acroblade

**Acroblade** is a fast grapple-and-sword action game for Windows. Swing across the arena with twin grapple hooks, slash bots with swords, survive waves, race the clock in **BLITZ** mode, Online play is coming soon.

## Download

**[Download Acroblade for Windows (free)](https://acroblade.com/)**

Direct installer: [Acroblade-Setup.exe](https://github.com/realfrostvortex-create/acroblade/releases/latest/download/Acroblade-Setup.exe) · version 1.1.0 · 77 MB · Windows 10/11, 64-bit.

Phone: open the [download page](https://acroblade.com/) on your phone and tap **Install on phone**.

## Features

- Twin-grapple swinging with sword and rifle combat
- BLITZ: a 90-second score attack, built for short sessions
- Bot arenas, difficulty levels and a score system
- Online matches for up to 4 players (coming soon)
- Full touch controls for phones: left-handed layout, vibration, gyro aiming, battery saver

## Install steps

1. Download `Acroblade-Setup.exe` and open it from your browser's download panel.
2. If Windows SmartScreen warns, click **More info**, then **Run anyway**. The installer is not code-signed yet.
3. Start Acroblade from the Start menu.

Verify the file: compare its SHA-256 with [SHA256.txt](SHA256.txt).
